## Features

- **System-wide mic mute.** No app (Zoom, Discord, Teams, browsers, OBS…) gets any audio while muted.
- **Real camera off.** Disables the webcam in Windows, like Device Manager does. Apps lose the picture at once and can't reopen it. If a program won't let go, PrivacyToggle tells you which one and asks before closing it.
- **Toggle or push-to-talk** for the mic, with global shortcuts that work even in fullscreen apps.
- **Enforce off.** Re-mutes a mic or re-disables a camera that something else turns back on, including headset buttons and newly plugged-in devices.
- **Per-device control.** Target all mics/cameras, or only the ones you pick.
- **Activity monitor.** See which apps are using the camera or microphone right now, and a timeline (1 hour to 7 days) of every app that used them. Time while a device is muted or off isn't counted. History stays on your PC in `%AppData%\PrivacyToggle\usage.json`.
- **Alerts, per device.** Windows notifications and on-screen `MIC OFF` / `CAM OFF` badges (clicks pass through them), set separately for the mic and the camera, each badge in its own screen corner.
- **Light and dark themes**, or follow Windows. Click sounds can be turned off.
- **In-app updates.** *Settings → About* checks GitHub for a new release, then downloads, verifies and installs it.

## Install

Download `PrivacyToggle-Setup-<version>.exe` from the [latest release](https://github.com/azahinhasan/Privacy-Toggle/releases/latest) and run it. Settings opens when setup finishes.

> [!NOTE]
> Camera control needs the small **PrivacyToggle Helper** service, which the installer sets up (one admin prompt). The tray app itself never runs as admin; mic control works without the service.

## Usage

- **Left-click** a tray icon to switch it. **Right-click** for both controls, Settings, *Start with Windows* and Exit.
- **Settings** pages:
  - **Overview:** both devices at a glance.
  - **Activity:** live use and history.
  - **Microphone / Camera:** mode, devices, start state, tray icon and alerts for each device.
  - **Shortcuts:** change the global hotkeys.
  - **General:** startup, appearance and sound.
  - **About:** version and updates.
- Changes save instantly to `%AppData%\PrivacyToggle\settings.json`.
- Launching the app again opens Settings of the running copy. `PrivacyToggle.exe --exit` closes it.

## 🛠️ Build

Requires the .NET 8 SDK.

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1   # release build + installer
dotnet run --project src/PrivacyToggle               # dev run
```

- `publish\PrivacyToggle.exe`: self-contained single file, no .NET install needed.
- `installer\Output\PrivacyToggle-Setup-<version>.exe`: built if [Inno Setup 6](https://jrsoftware.org/isinfo.php) is installed. Installs the helper service, offers *Start with Windows*, and the uninstaller turns cameras back on and removes everything.
- The version comes from `<Version>` in `src\PrivacyToggle\PrivacyToggle.csproj`; `build.ps1` passes it to the installer.
- Icons (tray, app and the images in `docs\`) are generated by `tools\make-icons.ps1`.
